PROJECT 02

Enterprise Identity, Endpoint & Infrastructure Migration

Led the migration of 120+ Windows devices from an on-premises Active Directory environment to a cloud-first Microsoft Entra ID and Microsoft Intune architecture.

The Challenge

Modernize a traditional on-premises environment while maintaining user access, preserving user profiles and data, and minimizing disruption during the migration.

What I Implemented

Migrated devices from AD domain-joined to Entra-joined, implemented Intune compliance and enrollment controls, Conditional Access and Zero Trust security, and supported the move of printers, file services and infrastructure toward cloud-based services.

Infrastructure Modernization

Migrated on-premises printers to Microsoft Universal Print, moved file shares to cloud storage, provisioned Azure Virtual Machines and supported LAN/WAN infrastructure, firewalls, UniFi wireless, DNS and DHCP.

Outcome

Established a more centralized cloud-first environment with modern identity, endpoint management and security controls across more than 120 Windows endpoints.
